# M1 To Multi-Timeframe Aggregation Result

## Status

Implemented `src/forex_bot/data/timeframe_aggregation.py` with synthetic tests in `tests/unit/test_timeframe_aggregation.py`.

## Supported Targets

- `M5`
- `M15`
- `H1`
- `H4`
- `D1AGG`

## Contract

Input is M1 candles for a single instrument. Non-M1 or mixed-instrument input is refused. Standard targets use deterministic bucket-start timestamps. H4 buckets follow the existing OANDA research alignment convention anchored to 17:00 New York time, and D1AGG is generated by first aggregating M1 to compatible H4 candles and then delegating to the existing `aggregate_h4_to_d1` implementation.

OHLC aggregation:

- open = first source M1 open
- high = max source M1 high
- low = min source M1 low
- close = last source M1 close
- volume = sum source M1 volume

Bid, ask, and mid OHLC are aggregated independently. Missing prices are not filled.

## Completeness Policy

Default policy is `omit`: a target candle is emitted only if every required source M1 timestamp is present and complete. Optional `mark_incomplete` emits the aggregate with `complete = false` while preserving coverage stats.

Weekend gaps are not filled. The engine only aggregates buckets represented by source rows.

## D1AGG Compatibility

D1AGG from M1 intentionally reuses the existing H4-to-D1AGG research-day convention:

- six complete H4 slots must exist for the OANDA trading day;
- the first five H4 candles form the research daily OHLC;
- the sixth rollover-adjacent H4 candle is excluded from OHLC and supplies the timestamp;
- native OANDA D candles are not used.
