## 5. Seed / reproducibility requirements

The BT adapter **must**:

- Derive the seed string as
  `f"{master_seed}|{instrument_name}|{bar_timestamp_iso}"` (UTF-8).
- Feed it through `hashlib.sha256(...).digest()`.
- Slice `[:8]` as `bar_random` (big-endian uint64) and `[8:16]` as
  `gate_random` (big-endian uint64) — matches
  `src/forex_bot/strategies/random_entry_anchor.py:84-88`.
- Convert the bar timestamp to UTC ISO 8601 via the same expression
  the bespoke strategy uses so the seed input is bit-identical.
- Compute the entry probability gate via
  `gate_random / float(2**64) < entry_probability_per_bar`.
- Select direction `"long"` when `(bar_random & 1) == 0` else
  `"short"`.

The BT adapter **must not**:

- Use `random.random()`, `numpy.random.*`, or Python's built-in
  `hash()`. These are non-deterministic across versions; they would
  silently break parity.
- Sweep, perturb, or otherwise mutate `master_seed`.
- Include any bar-`t` price data (close, high, low, open, volume)
  or ATR value in the seed input.
