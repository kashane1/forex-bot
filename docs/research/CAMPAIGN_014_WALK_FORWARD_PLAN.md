## 11. Limitations (binding)

1. **Fixture date-verification is PARTIAL** (per [`CAMPAIGN_014_EVENT_FIXTURE_DATE_VERIFICATION.md`](CAMPAIGN_014_EVENT_FIXTURE_DATE_VERIFICATION.md)).
   NFP + FOMC fully verified; BoJ partially verified for 2025-2026;
   ECB + BoE not WebFetch-verified. Any RESEARCH_PASS_UNAPPROVED
   verdict triggers a mandatory deeper audit.
2. **First-published event timestamps only** — emergency / unscheduled
   events (e.g. 2020-03-03 / 2020-03-15 FOMC; 2020-03-11 / 2020-03-19
   BoE) are deliberately excluded per scaffold-sprint design.
3. **Procedural NFP times** (8:30 ET wall-clock → 12:30/13:30 UTC) —
   small reschedules ≤ ±30 minutes are unchanged (only 1 day shifts
   matter to the H4 bar assignment; none observed in audit).
4. **Approximate central-bank announcement times** (FOMC 14:00 ET,
   ECB 12:15 UTC, BoJ ~03:00 UTC, BoE 11:00 UTC) — small drift
   (±1 hour) does not change the H4 bar assignment.
5. **No NFP / FOMC / ECB / BoJ / BoE actual / forecast / surprise /
   revision values** — the fixture is timestamp + class + ID only.

## 12. Why this plan does not approve anything

The plan only defines **where** to look (fold windows + universe).
The Phase 4 execution + Phase 5 verdict determine whether the
strategy survives the pre-committed gates. Even a clean PASS
produces `RESEARCH_PASS_UNAPPROVED`, which still requires:

- verifier-extension sprint
  (`infra-free-local-parity-verifier-calendar-event-window-anomaly-001`)
- a deliberate human-approval action per
  [`STRATEGY_APPROVAL_PROCESS.md`](STRATEGY_APPROVAL_PROCESS.md)

Item 6 of the six-evidence ladder is permanent: only a deliberate
human edit to `configs/approved_strategies.yaml` can promote the
strategy.
